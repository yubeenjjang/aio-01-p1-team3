# StudyMate 화면 이미지

Streamlit 화면에서 사용할 프로젝트 내부 이미지입니다. 페이지에서는 `Path(__file__).resolve().parents[1] / "assets"` 경로로 불러옵니다.

| 파일 | 용도 |
| --- | --- |
| `studymate-explorer-mascot-dashboard.png` | 홈 상단 환영 영역의 마스코트 |
| `studymate-cheer-01-thumbs-up.png` | 학습 기록 완료·격려 메시지 |
| `studymate-cheer-08-checklist-progress.png` | 학습 현황·진행 카드 |
| `studymate-web-02-learning-records.png` | 학습 기록 화면 디자인 참고 |
| `studymate-web-07-ai-feedback.png` | AI 분석 화면 디자인 참고 |
| `studymate-web-10-empty-error-states.png` | 빈 데이터·오류 상태 디자인 참고 |

디자인 참고용 전체 화면 이미지는 그대로 UI 배경으로 사용하지 않고, 카드 색상·여백·아이콘 배치의 참고 자료로 사용합니다.
