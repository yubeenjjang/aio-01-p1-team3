# 05-2｜API 명세서 (SSE·멀티턴·AI 분석 평가 확장)

> **구현 동기화 기준(2026-08-11):** 현재 FastAPI 라우터·Pydantic 스키마·프론트엔드 client가 사용하는 최종 계약입니다.

## 1. 문서 범위

이 문서는 [05 SSE·멀티턴 AI 확장 계획서](./05_SSE_멀티턴_AI_확장_계획서.md)의 신규 API 상세 계약입니다. 기존 MVP API는 [MVP API 명세서](./03_API_명세서_MVP.md)를 따릅니다.

추가·변경 API는 다음 네 영역으로 나눕니다.

- 관리자 운영 로그 SSE
- 멀티턴 학습 코치
- AI 분석 사용자 평가 및 관리자 조회
- 그룹 스터디 소유자 삭제

## 2. 공통 규칙

### 2.1 사용자 식별

현재 MVP와 동일하게 요청의 `user_id`를 사용합니다. 서버 세션/JWT가 도입되면 요청 본문의 `user_id`를 제거하고 인증 주체로 대체합니다.

- 사용자 API: 요청 `user_id`와 리소스 소유자 일치 여부 확인
- 관리자 API/SSE: `user_id`가 `users.role = 'admin'`인지 서버에서 확인
- 타인 리소스는 존재 여부를 노출하지 않도록 404로 통일

### 2.2 오류 응답

```json
{
  "code": "RATE_LIMITED",
  "message": "Gemini API 호출 한도를 초과했습니다.",
  "details": {},
  "trace_id": "uuid"
}
```

모든 오류는 `code`, `message`, `details`, `trace_id`를 포함합니다. `X-Trace-Id` 응답 헤더도 함께 반환합니다.

### 2.3 공통 오류 코드

| HTTP | code | 상황 |
| ---: | --- | --- |
| 400 | `VALIDATION_ERROR` | 필수 필드, 날짜, 평점, 길이 오류 |
| 401 | `LOGIN_FAILED` | 로그인 실패 |
| 403 | `ADMIN_REQUIRED` | 관리자 권한이 없음 |
| 404 | `CONVERSATION_NOT_FOUND` | 대화방이 없거나 타인 소유 |
| 404 | `NO_STUDY_RECORDS` | 분석 대상 기록 없음 |
| 429 | `RATE_LIMITED` | Gemini quota 초과 |
| 503 | `GEMINI_UNAVAILABLE` | Gemini 연결·서비스 장애 |
| 500 | `GEMINI_REQUEST_FAILED` | Gemini 응답 파싱·기타 오류 |

### 2.4 MVP API 추가 계약｜스터디 삭제

```http
DELETE /studies/{study_id}?user_id={uuid}
```

스터디 소유자만 삭제할 수 있습니다. 서비스는 `study_members`의 참여자 행을 먼저 삭제한 뒤 `studies` 행을 삭제하고 `study.delete` 운영 로그를 기록합니다.

- 성공: `204 No Content`
- `403 STUDY_OWNER_REQUIRED`: 요청 사용자가 소유자가 아님
- `404 STUDY_NOT_FOUND`: 스터디가 없음

## 3. 관리자 운영 로그 SSE

### `GET /events/stream?admin_user_id={uuid}`

관리자 대시보드·운영 로그·분석 평가 화면이 공유하는 SSE입니다. 일반 사용자 프론트엔드는 이 API를 호출하지 않습니다.

요청 헤더:

```http
Accept: text/event-stream
Cache-Control: no-cache
```

성공 응답:

```http
200 OK
Content-Type: text/event-stream; charset=utf-8
Cache-Control: no-cache
X-Accel-Buffering: no
```

이벤트:

```text
event: admin.log.updated
data: {"event_id":"uuid","action":"analysis.feedback.submit","status":"success","occurred_at":"2026-08-10T12:00:00Z"}

```

| event | data 필드 | 동작 |
| --- | --- | --- |
| `admin.log.updated` | `event_id`, `action`, `status`, `occurred_at` | 현재 운영 로그·평가 조회 API 재호출 |
| `error` | `code`, `message`, `occurred_at` | 연결 오류 표시, 재연결 시도 |
| keep-alive | 주석 이벤트 | 연결 유지 |

오류:

- `400 VALIDATION_ERROR`: 잘못된 UUID
- `403 ADMIN_REQUIRED`: 관리자 role이 아님
- Redis 장애는 HTTP 응답 이후 `error` 이벤트로 전달하고, 스트림이 종료되면 클라이언트가 재연결합니다.

## 4. 멀티턴 학습 코치 API

### `POST /chat/conversations`

빈 대화방을 생성합니다.

요청:

```json
{
  "user_id": "123e4567-e89b-12d3-a456-426614174000",
  "title": "Python 학습 질문"
}
```

`title`은 선택값이며 생략 시 기본 제목을 사용합니다.

응답 `201`:

```json
{
  "conversation_id": "uuid",
  "title": "Python 학습 질문",
  "created_at": "2026-08-10T12:00:00Z",
  "updated_at": "2026-08-10T12:00:00Z"
}
```

### `GET /chat/conversations?user_id={uuid}`

사용자의 대화방을 `updated_at DESC`로 조회합니다.

응답 `200`:

```json
{
  "items": [
    {
      "conversation_id": "uuid",
      "title": "Python 학습 질문",
      "updated_at": "2026-08-10T12:00:00Z",
      "message_count": 4
    }
  ],
  "total": 1
}
```

### `GET /chat/conversations/{conversation_id}/messages?user_id={uuid}`

선택한 대화방의 메시지를 시간순으로 조회합니다.

응답 `200`:

```json
{
  "items": [
    {
      "message_id": "uuid",
      "role": "user",
      "content": "집중력을 높이는 방법을 알려줘.",
      "created_at": "2026-08-10T12:00:00Z"
    },
    {
      "message_id": "uuid",
      "role": "model",
      "content": "짧은 목표를 정하고 ...",
      "created_at": "2026-08-10T12:00:02Z"
    }
  ],
  "total": 2
}
```

### `POST /chat/conversations/{conversation_id}/messages`

질문을 저장하고 최근 대화 이력을 포함해 Gemini 답변을 생성합니다.

요청:

```json
{
  "user_id": "123e4567-e89b-12d3-a456-426614174000",
  "content": "FastAPI의 Depends를 쉽게 설명해줘."
}
```

응답 `201`:

```json
{
  "user_message": {
    "message_id": "uuid",
    "role": "user",
    "content": "FastAPI의 Depends를 쉽게 설명해줘.",
    "created_at": "2026-08-10T12:00:00Z"
  },
  "model_message": {
    "message_id": "uuid",
    "role": "model",
    "content": "Depends는 ...",
    "created_at": "2026-08-10T12:00:02Z"
  }
}
```

처리 규칙:

1. 대화방 소유자 확인
2. `user` 메시지 저장
3. 최근 20개 메시지를 Gemini `contents`로 변환
4. 답변 성공 시 `model` 메시지 저장
5. 성공·실패 모두 `chat.message` 운영 로그 기록

### `DELETE /chat/conversations/{conversation_id}?user_id={uuid}`

소유자 대화방과 메시지를 함께 삭제합니다. 성공 응답은 `204 No Content`입니다.

## 5. AI 분석 사용자 평가 API

### `POST /analyses/feedback`

분석 결과에 대한 평가를 생성하거나 기존 평가를 수정합니다.

요청:

```json
{
  "user_id": "123e4567-e89b-12d3-a456-426614174000",
  "period_start": "2026-08-01",
  "period_end": "2026-08-31",
  "rating": 5,
  "comment": "다음 목표를 정하는 데 도움이 되었습니다."
}
```

검증:

- `rating`: 정수 1~5
- `comment`: 생략 가능, 최대 1000자
- `period_start <= period_end`
- 현재 구현은 해당 기간의 학습 기록이 한 건 이상 존재하는지 확인하며, 기록이 없으면 `404 NO_STUDY_RECORDS`를 반환합니다.

응답 `201` 또는 `200`:

```json
{
  "feedback_id": "uuid",
  "period_start": "2026-08-01",
  "period_end": "2026-08-31",
  "rating": 5,
  "comment": "다음 목표를 정하는 데 도움이 되었습니다.",
  "created_at": "2026-08-10T12:10:00Z",
  "updated_at": "2026-08-10T12:10:00Z"
}
```

동일 사용자·동일 기간 평가가 이미 있으면 새 행을 만들지 않고 `200`으로 수정 결과를 반환합니다.

### `GET /analyses/feedback?user_id={uuid}&period_start=&period_end=`

사용자가 자신의 특정 분석 기간 평가를 조회합니다. 없으면 `404 FEEDBACK_NOT_FOUND`를 반환합니다.

### `GET /admin/analysis-feedback`

관리자만 전체 평가를 조회합니다.

지원 Query:

| Query | 타입 | 설명 |
| --- | --- | --- |
| `user_id` | UUID | 관리자 권한을 확인할 사용자, 필수 |
| `rating` | integer | 특정 평점만 조회, 1~5 |
| `from` | date | 평가 생성일 시작 |
| `to` | date | 평가 생성일 종료 |
| `limit` | integer | 기본 50, 최대 200 |
| `offset` | integer | 기본 0 |

응답 `200`:

```json
{
  "items": [
    {
      "feedback_id": "uuid",
      "user_id": "uuid",
      "user_name": "홍길동",
      "period_start": "2026-08-01",
      "period_end": "2026-08-31",
      "rating": 5,
      "comment": "도움이 되었습니다.",
      "created_at": "2026-08-10T12:10:00Z",
      "updated_at": "2026-08-10T12:10:00Z"
    }
  ],
  "total": 1,
  "average_rating": 5.0,
  "rating_distribution": {"1": 0, "2": 0, "3": 0, "4": 0, "5": 1}
}
```

관리자 API는 비밀번호, API 키, Gemini 원문 프롬프트를 반환하지 않습니다. 사용자 이름·평가 의견의 표시 범위는 개인정보 정책에 따라 제한할 수 있습니다.

## 6. 운영 로그 action

| action | 성공·실패 기록 시점 |
| --- | --- |
| `chat.conversation.create` | 대화방 생성 |
| `chat.message` | 질문·답변 생성 또는 Gemini 오류 |
| `chat.conversation.delete` | 대화방 삭제 |
| `analysis.feedback.submit` | 평가 생성·수정 또는 검증 오류 |
| `admin.analysis_feedback.list` | 관리자 평가 조회 |
